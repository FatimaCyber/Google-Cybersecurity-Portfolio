# **Project Description**

This project was completed as part of the **Google Cybersecurity Professional Certificate** to demonstrate the practical application of the **NIST Cybersecurity Framework (CSF)** in responding to a cybersecurity incident.

The objective of this project is to analyze a real-world security scenario, identify the nature and impact of the attack, and document a structured incident response using the five core functions of the NIST Cybersecurity Framework: **Identify, Protect, Detect, Respond, and Recover**. Through this analysis, the project highlights how cybersecurity professionals investigate incidents, implement security controls, and restore affected systems while reducing the risk of similar attacks in the future.

Instead of focusing on offensive security techniques, this project emphasizes defensive cybersecurity practices, incident handling, risk assessment, and recovery planning based on industry-recognized standards.

## **Scenario**

A company experienced an unexpected outage when its network services suddenly became unavailable, preventing employees and users from accessing critical business resources. Following an investigation, the cybersecurity team determined that the disruption was caused by a **Distributed Denial-of-Service (DDoS) attack** using an **ICMP flood**.

In this attack, multiple compromised devices continuously transmitted a high volume of ICMP Echo Request (ping) packets to the organization's public-facing network. The excessive traffic overwhelmed network bandwidth and system resources, making legitimate requests impossible to process and causing essential services to become inaccessible.

To mitigate the incident, the cybersecurity team blocked the malicious traffic, temporarily disabled non-essential network services to reduce congestion, restored critical systems, and implemented additional security measures to strengthen the organization's defenses against future DDoS attacks.

## **Project Objectives**

* Analyze a DDoS attack scenario and assess its impact on network availability.  
* Apply the NIST Cybersecurity Framework to a real-world incident response process.  
* Identify appropriate security controls to protect network infrastructure.  
* Demonstrate the stages of incident detection, response, and recovery.  
* Develop professional cybersecurity documentation using industry best practices.
